# 夕暮れの部屋 — Acrylic Star

机に積まれた本。窓辺で揺れるカーテン。消える直前に、少しだけ暖かくなる照明。

どこにでもありそうな部屋の見慣れた光景。

けれど、さっきまで当たり前だった景色が、いつまでも同じとは限りません。

## 遊び方

部屋の気になる場所へ近づいて、クリックして調べてください。
本やスマートフォンをどかす、机の引き出しを開ける、家具を開くなど、見た目だけではわからない仕掛けがあります。

**何かを見つけても、進むことだけが正解とは限りません。見覚えのある場所や、来た道のことも覚えておくと役に立つかもしれません。**

見慣れた空間の歪んだ姿。

急ぐ必要はありません。光や素材、小さな変化も楽しみながら歩いてみてください。

## 操作

キーボードとマウスのあるPCでのプレイをおすすめします。

| 操作 | 内容 |
| --- | --- |
| W / A / S / D | 見ている方向を基準に移動 |
| Bを押しながらWASD | ダッシュ |
| 画面をドラッグ | 見回す |
| 気になるものをクリック | 調べる・動かす・開閉する |
| 画面下のボタン | 机やベッドなどの視点へ移動 |
| 「ベッドの下」ボタン | 身をかがめてベッドの下へ潜る |
| ポーチの検査中にドラッグ | ポーチを回転 |
| ポーチの検査中にホイール／ピンチ | 拡大・縮小 |
| 「部屋に戻る」／Esc | 検査画面を閉じる |
| 会話中にクリック／Enter／Space | 次の台詞へ進む |

※ ベッドの下ではダッシュできません。  
※ 廊下では、画面下の視点ボタンではなくWASDで移動します。  
※ 会話は、操作しなくても自動で進みます。

## 調べられるもの

- **本・スマートフォン**：どかして、その下を確認できます。
- **机の引き出し**：中の印刷物をクリックすると、全文を読めます。
- **クローゼット**：扉を開き、服やハンガーを一つずつ床に置けます。
- **照明スイッチ**：部屋の明かりを切り替えられます。
- **デスクランプ**：部屋の照明とは別に点灯・消灯できます。
- **ベッドの下**：低い目線で、普段は見えない場所を探せます。
- **ドア**：開けて、部屋の外へ進めます。

操作できるものにカーソルを合わせると、画面下に説明が表示されます。

## このゲームについて

### 照明で遊ぶ

照明はすぐに点き、消すときには淡い暖色の余韻を残します。
明るさを変えると、同じ部屋でも少し違った表情になります。

### 歩くたびに変わる部屋

廊下の先には、家具の配置が異なる部屋が続きます。
ときには、**ただ配置が違うだけではない**部屋もあります。

一度訪れた部屋は、同じプレイ中なら引き返しても同じ配置・異変です。
先へ進み続けても、最初の部屋へ自動的に一周して戻ることはありません。

### 最後まで、ゆっくり

探索の先には、エンドロールと短い会話のエピローグがあります。

文字を読みながら、最後の部屋の様子も眺めてもらえたらうれしいです。

## 起動方法

1. [こちらのリンクから遊べます](https://wakana-code.github.io/the-frontroom/)
2. インターネットに接続した状態で、ブラウザで開きます。

Three.jsなどの外部ライブラリをCDNから読み込むため、起動時にインターネット接続が必要です。

ファイルを直接開いて起動しない場合は、ローカルWebサーバーや静的サイトのホスティング環境で開いてください。

### 推奨環境

- 最新版のChrome、Edge、Firefox、Safariなど
- WebGLを利用できる環境
- キーボードとマウス
- ブラウザのハードウェアアクセラレーションが有効な環境

影、水面の反射、透明素材などを描画するため、端末によっては動作が重くなる場合があります。

## 注意事項

- 進行状況のセーブ機能はありません。ページを再読み込みすると最初からになります。
- 部屋には、不気味に感じる表現や現実離れした配置が登場します。
- 歩行・ダッシュ時の画面の揺れや、終盤に古い映像を模したノイズ・短い画面の乱れがあります。苦手な方は無理せず休憩してください。
